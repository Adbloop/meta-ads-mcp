# Example prompts

Plain-language prompts you can paste into Claude, ChatGPT, or Cursor once the Adbloop Meta Ads MCP is connected. Placeholders like `<account>` are for you to fill in — no real IDs are shown here.

## Get oriented
- "List my connected Facebook ad accounts."
- "Show me the campaigns running in `<account>` and their spend this week."
- "Pull last 7 days of insights for account `<account>` — CPR, CTR, spend."

## Create safely (dry run first)
- "Validate a $10/day Facebook conversions campaign for `<account>` targeting India, ages 25–45 — don't create it, just check it."
- "Estimate how big a batch it is if I create 50 campaigns from this plan."

## Bulk create
- "Create 20 Facebook conversion campaigns from this Google Sheet, all **paused**, $10/day each, in account `<account>`."
- "Bulk-create Instagram traffic campaigns for these 5 products, one campaign each, paused."
- "Create the same 10-campaign template across my 3 client accounts, paused." *(agency / multi-account)*

## Manage
- "Pause every campaign in `<account>` that spent over `<amount>` with zero conversions yesterday."
- "Raise the daily budget on `<campaign>` to `<amount>`."
- "Resume the campaigns I paused in `<account>`."

## Reporting
- "Which campaigns in `<account>` have the best cost per result this month?"
- "Show the creatives in my library I haven't used yet."

> Tip: start with **validate / paused**, review in the [dashboard](https://app.adbloop.com), then go live.
